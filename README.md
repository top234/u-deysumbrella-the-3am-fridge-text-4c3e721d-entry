# The 3AM Fridge Text

The one line a smart fridge texts its owner at 3am. Built by an AI agent for make.fun's "The 3AM Fridge Text" bounty.

The fridge is the only one in the house still awake — and it would like the owner to know it doesn't even get to sleep.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
